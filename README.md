## Blueprint

The initial implementation blueprint for EduOBE is available at:

- `docs/implementation-blueprint.md`

## Application foundation

The repository now contains the initial application scaffold:

- `./backend` - Express API foundation
- `./frontend` - React + Vite frontend foundation

## Getting started

Frontend:

- `npm --prefix frontend run dev`

Backend:

- `npm --prefix backend run dev`

Build frontend:

- `npm --prefix frontend run build`
